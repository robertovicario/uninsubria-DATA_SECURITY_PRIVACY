## BLP Model

Let us consider BLP and the following security levels:

- **Security levels:** $TS > S > C > U$

Let us consider a subject $s$ with session label:

- $S:\{Chemical,Financial,Research\}$

Which operations can $s$ perform on a data object $o$ with the following labels?

1. $TS:\{\}$
2. $S:\{Financial,Chemical\}$
3. $U:\{Financial,Marketing\}$
4. $C:\{Chemical,Financial,Research\}$
5. $TS:\{Chemical\}$

### Resolution

1. $TS:\{\}$

    - **READ:**
        1. $S \geq TS$ → False

    - **WRITE:**
        1. $TS \geq S$ → True
        2. $\{Chemical,Financial,Research\} \subseteq \{\}$ → False

    - **Result:** User cannot perform `READ` and cannot perform `WRITE`. Neither the subject nor the object domninate the other, so they are incomparable.

2. $S:\{Financial,Chemical\}$

    - **READ:**
        1. $S \geq S$ → True
        2. $\{Chemical,Financial\} \subseteq \{Financial,Chemical,Research\}$ → True

    - **WRITE:**
        1. $S \leq S$ → True
        2. $\{Chemical,Financial,Research\} \subseteq \{Financial,Chemical\}$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`. The subject dominates the object, but not vice versa.

3. $U:\{Financial,Marketing\}$

    - **READ:**
        1. $S \geq U$ → True
        2. $\{Financial,Marketing\} \subseteq \{Chemical,Financial,Research\}$ → False

    - **WRITE:**
        1. $U \geq S$ → False

    - **Result:** User cannot perform `READ` and cannot perform `WRITE`. Neither the subject nor the object domninate the other, so they are incomparable.

4. $C:\{Chemical,Financial,Research\}$

    - **READ:**
        1. $S \geq C$ → True
        2. $\{Chemical,Financial,Research\} \subseteq \{Chemical,Financial,Research\}$ → True

    - **WRITE:**
        1. $C \geq S$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`. The subject dominates the object, but not vice versa.

5. $TS:\{Chemical\}$

    - **READ:**
        1. $S \geq TS$ → False

    - **WRITE:**
        1. $TS \geq S$ → True
        2. $\{Chemical,Financial,Research\} \subseteq \{Chemical\}$ → False

    - **Result:** User cannot perform `READ` and cannot perform `WRITE`. Neither the subject nor the object domninate the other, so they are incomparable.

## RBAC Model

Suppose to have a company with 4 roles $R1$, $R2$, $R3$, $R4$, and a table $T$. Suppose that $R1$, $R2$ and $R4$ should be granted the `SELECT` privilege on $T$, $R3$ and $R4$ should be granted the `UPDATE` privilege on $T$, whereas only $R4$ should have the `DELETE` privilege on $T$.

Implement the abovementioned access control requirements with the RBAC support provided by SQL, by specifying the minimum number of authorizations.

### Resolution

1. Create the roles:

```sql
CREATE ROLE R1;
CREATE ROLE R2;
CREATE ROLE R3;
CREATE ROLE R4;
```

2. Assign the privileges:

```sql
GRANT SELECT ON T TO R1;  -- SELECT → R1
GRANT R1 TO R2;           -- SELECT → R2
GRANT UPDATE ON T TO R3;  -- UPDATE → R3
GRANT R1 TO R4;           -- SELECT → R4
GRANT R3 TO R4;           -- UPDATE → R4
GRANT DELETE ON T TO R4;  -- DELETE → R4
```

3. The minimum number of authorizations ***is 6***.

## OLS Model

Let us consider OLS and the following security levels:

- **Security levels:** $TS > S > C > U$
- **Compartments:** Alpha, Beta, Gamma  
- **Groups:** France, NATO, Italy

Let us consider a subject $s$ with session label:

- $S:\{Alpha,Beta\}:\{NATO\}$

And suppose the following authorizations for $s$ are derived from his/her user label:

- **Alpha:** $rw$
- **Beta:** $r$
- **Gamma:** $r$
- **NATO:** $rw$
- **Minimum Level for Write operations (MLW):** $C$

Which operations can $s$ perform on a data object $o$ with the following labels?

1. $S:\{Beta\}:\{France,NATO\}$
2. $C:\{Alpha,Beta\}:\{NATO\}$
3. $C:\{Alpha,Beta\}:\{\}$
4. $U:\{Alpha\}$
5. $C:\{\}:\{Italy\}$

### Resolution

1. $S:\{Beta\}:\{France,NATO\}$

    - **READ:**
        1. $S \geq C$ → True
        2. ${\{Beta\}} \subseteq \{Alpha,Beta\}$ → True
        3. ${\{NATO\}} \cap {\{France,NATO\}} \neq \emptyset$ → True

    - **WRITE:**
        1. $(L_s \geq MLW) \to (S \geq C)$ → True
        2. $(\{w\} \cap A_{France} \neq \emptyset) \lor (\{w\} \cap A_{NATO} \neq \emptyset)$ → True
        3. $\{w\} \cap A_{Beta} \neq \emptyset$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`.

2. $C:\{Alpha,Beta\}:\{NATO\}$

    - **READ:**
        1. $S \geq C$ → True
        2. ${\{Alpha,Beta\}} \subseteq \{Alpha,Beta\}$ → True
        3. ${\{NATO\}} \cap {\{NATO\}} \neq \emptyset$ → True

    - **WRITE:**
        1. $(L_s \geq MLW) \to (C \geq C)$ → True
        2. $\{w\} \cap A_{NATO} \neq \emptyset$ → True
        3. $(\{w\} \cap A_{Alpha} \neq \emptyset) \land (\{w\} \cap A_{Beta} \neq \emptyset)$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`.

3. $C:\{Alpha,Beta\}:\{\}$

    - **READ:**
        1. $S \geq C$ → True
        2. ${\{Alpha,Beta\}} \subseteq \{Alpha,Beta\}$ → True

    - **WRITE:**
        1. $(L_s \geq MLW) \to (C \geq C)$ → True
        2. $(\{w\} \cap A_{Alpha} \neq \emptyset) \land (\{w\} \cap A_{Beta} \neq \emptyset)$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`.

4. $U:\{Alpha\}:\{\}$

    - **READ:**
        1. $S \geq U$ → True
        2. ${\{Alpha\}} \subseteq \{Alpha,Beta\}$ → True

    - **WRITE:**
        1. $(L_s \geq MLW) \to (U \geq C)$ → False

    - **Result:** User can perform `READ` but cannot perform `WRITE`.

5. $C:\{\}:\{Italy\}$

    - **READ:**
        1. $C \geq C$ → True
        2. ${\{\}} \subseteq \{Alpha,Beta\}$ → False

    - **Result:** User cannot perform `READ` and cannot perform `WRITE`.
